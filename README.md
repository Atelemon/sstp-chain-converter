# SSTP 链式节点转换器

GitHub Pages 可部署的静态转换页面。

固定 TXT 地址：
https://raw.githubusercontent.com/Atelemon/sstp-chain-converter/main/nodes.txt

使用方法：
1. 打开 GitHub Pages 页面。
2. 粘贴原始 sstp:// 节点。
3. 点击转换并复制结果。
4. 将结果作为 nodes.txt 的内容提交到仓库。
5. 让 edgetunnel 读取固定 Raw 地址。

注意：本仓库公开。nodes.txt 如果包含 SSTP 用户名和密码，任何人都可以读取，Git 历史也会保留旧版本。
